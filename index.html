Projects

Three backend systems I've helped build and evolve, each tackling a different engineering challenge. Hover or tap the diagrams to explore them.

01 Realtor.com · Tavant

RCS Engine

A multi-service platform (Proposals, Users, Authentication and API Gateway) that supports 7,300+ active agents and 50,000+ proposals a month.

  • Migration without downtime. A dual-store layer reads legacy agent templates from MySQL and copies them into DynamoDB the first time they're used. No manual migration of 7,300+ agent records was needed.
  • Scores that stay current. Kafka events recalculate proposal readiness when a template changes, replacing a batch job that left scores out of date.
  • 7,300+ active agents
  • 50K+ proposals / month

02 Realtor.com · Tavant

Unified Communication Service

A Java 17 / Spring Boot platform with REST APIs, serving more than 100,000 requests a day with transaction management on MySQL.

  • Built for failure. Asynchronous processing on Kafka with Dead Letter Queues, so transactions aren't lost when downstream services are down.
  • 40% faster reports. Reworked MySQL schemas and query plans with composite indexes.
  • Secure by default. Spring Security with JWT validation, DynamoDB audit logs and AWS Secrets Manager for configuration.
  • 100K+ requests / day
  • 40% faster reports

03 UpNest.com · Tavant

UpNest Platform Modernization

Breaking a legacy Struts2 / Spring MVC monolith into modular Spring services while the product kept shipping.

  • ML agent matching. An ONNX model inside a Java service scores and ranks agents for incoming leads. It was released through an A/B test to 25% of production traffic.
  • Strangler Fig migration. New REST services cut response payloads by 60%, and dual writes kept the legacy and MariaDB databases in sync during rollout.
  • Enterprise SSO. Okta SSO / SAML for advisors and admins, with identity aliasing between Okta and internal accounts.
  • 60% smaller payloads
  • 25% of traffic in A/B test
