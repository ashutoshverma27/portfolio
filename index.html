About

I'm a backend-focused engineer with 5.2 years of experience building server-side systems for real estate and proptech platforms — Realtor.com and UpNest.

My day-to-day is designing REST APIs and secure, event-driven microservices in Java, Spring Boot and TypeScript / NestJS, backed by MySQL, MariaDB and DynamoDB, and wired together with Apache Kafka on AWS. I've spent a lot of that time on the unglamorous work that makes products possible: breaking legacy Struts2 / Spring MVC monoliths apart, keeping two data stores in sync mid-migration, and making sure no event gets lost when a downstream service goes down.

I also shipped an ONNX machine-learning model inside a Java service to match consumers with the right agents, rolled out behind an A/B test to a quarter of production traffic.

I work in Agile teams with CircleCI pipelines and SonarCloud quality gates, and I'm a heavy user of AI coding tools like Claude Code and GitHub Copilot.

Realtor.com

Unified Communication Service

A Java 17 / Spring Boot communication platform with REST APIs serving 100,000+ requests a day, with transaction management on MySQL.

Resilient by design

Asynchronous processing on Kafka with Dead Letter Queues, so very few transactions are lost when downstream services go down.

Faster, leaner reads
